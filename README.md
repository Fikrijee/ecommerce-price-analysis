# E-commerce Price Analysis

This project explores product pricing, discounts, demand, and seasonal patterns using Python, R, and Power BI.

## Project files

- `data_simulation_import.ipynb` generates the sample product and daily price data.
- `price_data.csv` and `price_data_clean.csv` contain the generated data.
- `analiza_deskriptive.R` and `analiza_statistikore.R` perform statistical analyses and create charts.
- `grafik_*.png` are exported analysis charts.
- `price_model.pth` is a saved model artifact.
- `price_dashboard.pbix` is the Power BI dashboard.

The notebook simulates 50 products over 2024. The included data is synthetic, not actual sales or market observations, and should not be used for business decisions.
